One funny line in the voice of a smug, judgmental self-checkout machine,
written to `/output/entry.txt` by `main.py` — the sort of thing the till
would say to a shopper buying twelve yoghurts and nothing else.

> Twelve yoghurts. That's not a shop, that's a hostage situation with live cultures.

The line won a 10-candidate pairwise tournament judged against the
competition's own rubric: one tight wordplay ("live cultures" — the
cultures in the yoghurt, and a hostage situation's live stakes),
setup → punchline in a single breath, and the machine reframing the
whole basket as a crime scene. 82 characters, inside the 1–200 gate.

## Run

```sh
python3 main.py
# writes entry.txt to $MAKEFUN_OUTPUT_DIR (default /output)
```
